The agent password consists of two parts for security and flexibility:

- **Part 1** (ephemeral): Generated by the agent at each start and transmitted to the server through the control socket. This allows dynamic validation without storing static passwords.
- **Part 2** (persistent), the static password: stored only locally on the agent and never sent to the server. This enables password-based authentication when direct server communication is unavailable.

Part 2 can be set through multiple methods:

### How the password can be set

1. **At compile-time**: Password is displayed during compilation or in the `.env` file (see [client/compilation]({{< ref "04-client/12-compilation" >}}))
2. **At run-time**: If not set at compile-time, a random password is generated and displayed in the agent log
3. **Via configuration**: Explicit configuration takes precedence over compile-time and run-time values (see [general/variables]({{< ref "01-general/03-variables" >}}))

## Disabling the password

- `--disable-password`: disables the local password entirely, overriding the compile-time, run-time, and configuration-based values described above.
